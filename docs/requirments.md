## Functional Requirements

- **FR1** – The system shall read the selected data source.
- **FR2** – The system shall validate input data.
- **FR3** – The system shall transform the input data.
- **FR4** – The system shall identify invalid records.
- **FR5** – The system shall load validated data into PostgreSQL.
- **FR6** – The system shall provide data for analytical queries.

## Non-Functional Requirements

- **NFR1** – The pipeline should be reproducible.
- **NFR2** – The source code should be maintainable.
- **NFR3** – Data processing should be documented.
- **NFR4** – Data quality checks should be implemented.
- **NFR5** – The system should handle expected input errors.
